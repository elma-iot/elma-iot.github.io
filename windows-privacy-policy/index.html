About this policy

This policy covers ELMA IoT – ESP32 Toolkit for Windows, developed by Elnur Mehdiyev, Microsoft Store product 9NHT3C98QH5M. The Android application has a separate policy. Contact elik745i@gmail.com for privacy questions.

Local files and settings

The application stores device configurations, visual Logics projects, interface preferences, imported parts, firmware images, build workspaces, downloaded compiler archives and diagnostic logs on your PC. Plotter recordings and files you export are stored in the folder you choose or the application's local working folder.

Configurations can contain Wi-Fi names and passwords, broker addresses and credentials, device addresses, GPIO assignments and automation logic. Saved or exported project files may contain these values; do not treat ordinary configuration files as encrypted secrets. Local crash diagnostics are not automatically uploaded to the developer. Review and remove credentials before sharing project files, recordings or logs.

Device access

When you use connection, monitoring, compile or flash features, the application can access selected USB serial ports and communicate with ESP32 or ESP8266 devices. Device discovery checks your local network for compatible devices. Wi-Fi, MQTT and OTA features communicate with the device or broker you select and send the configuration, firmware, commands or credentials required for that requested operation.

Device data and recordings are processed locally unless you choose to transfer them to a device, broker or other destination. Devices, brokers and firmware have their own settings and retention behavior. Only use devices and networks that you are authorized to manage.

Optional compiler downloads

The Microsoft Store installation contains the application interface, designer and USB flasher. Opening the interface does not require downloading compiler packages. The first compilation for a board family asks to download the missing compiler components and SDK packages, showing their sizes and source hosts.

The application compiler and public SDK assets are hosted on GitHub Releases. Some SDKs prefer a pinned official PlatformIO registry download and use a pinned public GitHub asset as a fallback. Advanced SDK setup may also contact its upstream package services when required. These hosts receive your IP address, download request, package/version information and ordinary network metadata. The application's download request does not attach your device configuration, passwords or Logics project.

Archives are checked against application-pinned sizes and SHA-256 hashes before installation. Completed tools and archives are cached in writable per-user storage for reuse, including offline reuse where the installed SDK supports it. Compiler telemetry is disabled in the build environment configured by the application.

Other network services

Online radio-directory features contact Radio Browser for country and station lists. The service receives your IP address and the query information, such as the country you choose. Opening or playing an external media URL connects to that provider. Device pages, media, artwork, help links and other external URLs can contact their respective hosts. MQTT tests contact the broker you specify, which may be outside your local network.

Third-party hosts apply their own privacy practices. Relevant policies include GitHub's Privacy Statement, PlatformIO's Privacy Policy, Radio Browser information and the policy of your selected broker or media provider. Microsoft Store account, installation and Store diagnostic information is handled by Microsoft under its Privacy Statement.

Accounts, advertisements and analytics

The Windows application does not require an ELMA cloud account and has no developer-operated configuration-upload, analytics or automatic crash-reporting service. This Windows release does not contain the Android app's Google advertising or billing features. The Windows toolkit is provided without in-app advertisements or purchases.

Retention, deletion and your choices

You choose when to connect to a device, download optional tools, export a file or contact support. Saved projects, recordings, build outputs and cached tools remain on your PC until you remove them. Windows manages packaged app storage when uninstalling, but exported files and files held outside that managed storage may remain and must be removed separately. Uninstalling the application does not erase firmware or settings on your ESP, broker records or third-party service logs.

Keep backups of projects you want before removing local data. To request access, correction or deletion of information you sent to the developer for support, email elik745i@gmail.com. There is no ELMA cloud account to delete.

This website and support

This static site has no ELMA analytics scripts, advertisements, sign-in, tracking pixels or contact form. It is hosted on GitHub Pages, which processes visitor IP addresses for security under GitHub's Pages data collection practices.

If you contact the developer by email, the developer receives your email address, message and attachments. This correspondence is used to respond and retained as needed to resolve the request or meet applicable obligations; email providers also process it. GitHub issues are public. Never post passwords, private configurations or sensitive recordings in a public issue.

This policy will be updated if the Windows application's data handling changes. The effective date above identifies the current revision. See Support for project help.
